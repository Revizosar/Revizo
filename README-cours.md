# REVIZO — Module matières et cours

## Fichiers à remplacer
- `index.html` à la racine
- `css/style.css`
- `js/app.js`
- `js/data/school-data.js`

Garde exactement les dossiers `css/` et `js/data/`.

## Ce qui fonctionne
- Matières affichées selon le niveau collège ou lycée.
- Navigation matière → chapitre → cours.
- Introduction, points essentiels et exemple expliqué.
- Français / anglais.
- Profil élève conservé dans le navigateur.

## Cours de démonstration inclus
- 3e : théorème de Pythagore et loi d'Ohm.
- Terminale : limites, dérivation et charge d'un condensateur dans un circuit RC.

Les autres classes et matières sont affichées, mais leurs cours restent à compléter. Les matières, séries et chapitres sont une base de démonstration à vérifier avec les programmes officiels avant publication. Ce projet n'est pas encore un APK.
